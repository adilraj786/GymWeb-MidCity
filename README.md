## 📌 Overview

**GymWeb MidCity** is a modern gym website developed to provide an engaging and professional online experience for gym members and potential customers.

The project focuses on:

* Modern and responsive UI
* Fitness-focused visual design
* Smooth animations and interactions
* Clear presentation of gym services
* Mobile-first responsiveness
* Reusable React components
* Clean and maintainable frontend architecture

The application is built using **React 19**, powered by **Vite**, and styled with **Tailwind CSS**.

## 🚀 Getting Started

Follow the steps below to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/adilraj786/GymWeb-MidCity.git
```

### 2. Navigate to the project

```bash
cd GymWeb-MidCity
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL displayed by Vite, typically:

```text
http://localhost:5173
```
